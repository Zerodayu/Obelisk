## Numerical verification rules and limitations

The original narrow exact-sentence checker matched zero claims in ST-AI-001 and flagged prose; an empty mismatch list was not accepted as proof. The new checker records text, character spans, metric, expected value, actual value, method, outcome and scope explanation for each identifiable numeric token.

- Explicit per-CLO fractions use that CLO's failed numerator and total denominator. Multi-CLO statements require explicit per-CLO or identical-across-outcomes wording; this fixture has identical per-CLO distributions.
- Unique students and student-CLO records are separate counts.
- Direct fractions convert to percent; indirect/composite already use percent.
- A below-threshold average uses failed records; an explicit all-student average uses all records. An unqualified average is interpreted as composite only when composite threshold is the sole metric context in the sentence.
- Rounded percentage claims allow half a unit at the stated decimal precision; 51.2% correctly represents 51.25% at one decimal place. Counts must match exactly.
- CLO/course/section identifiers are recorded as identifiers. Unsupported numbers, forecasts, word-number claims or unresolved metric/population scope remain MANUAL REVIEW.
- Any supported contradiction yields MISMATCH and FAIL. Unresolved numerical claims prevent ST-AI-004 PASS; no identifiable claim yields NOT APPLICABLE for that claim scope.

Built-in deterministic negative controls detect wrong student count, per-CLO numerator/denominator, threshold, failed mean and all-student mean. Forecast wording is explicitly retained for review. These controls do not run any other Pre-UAT test ID or make provider calls.

The first saved-response pass [recorded nine manual items](evidence/20261011T093750_493757Z_live_ai_evidence/ST-AI-004_result.txt), so ST-AI-004 was initially BLOCKED. Subsequent general parsing rules for metadata identifiers, `fall below`/`failed to meet`, composite threshold and explicitly scoped means were validated with negative controls. A **new evidence-only run** verified those claims; earlier evidence was not changed. No response wording or test data was rewritten to obtain PASS.

This parser is intentionally bounded to documented grammars and these synthetic fixtures. It does not certify all possible paraphrases, implicit logical claims, inferred causes or future model output.
