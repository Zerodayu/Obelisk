## Final production changes

- `app/etl/extract/extractor.py::_read_numeric_cell`: dedicated strict parser at period-score and indirect-rating callers only. It accepts finite numbers/numeric strings, treats blank/whitespace as missing, and rejects malformed nonblank strings, Excel errors, booleans and nonfinite values. Conversion exceptions are suppressed to avoid exposing raw invalid text. `_as_optional_float` and its unrelated metadata/max-cell callers are unchanged.
- `_validate_roster_ids`: rejects repeated trimmed nonblank IDs separately on Direct/Indirect before insertion. Cross-sheet ID matching, optional IDs and existing ID conversion/case behavior remain unchanged.
- Identity lookup: groups indirect names into candidate lists instead of overwriting them. Unique ID matches take precedence; fallback must be unambiguous on the matching rosters. Missing-ID duplicate names are rejected before extraction keys can overwrite records. Distinct matching IDs sharing a name remain valid.
- `_validate_clo_codes`: rejects duplicate discovered codes in each worksheet, after existing trimming and indirect header token extraction. Matching codes across sheets, dynamic discovery and case behavior are preserved.
- `app/core/exceptions.py::WorkbookValidationError`: existing OBELISKError mechanism with `sheet_name`, `cell`, `field`, `reason`, and optional `conflicting_cell`. Messages/details contain no student names, IDs or raw invalid values. The existing worker catches OBELISKError and serializes to_dict; that integration path was inspected only, not executed.

Only these two application files changed in this final correction. Earlier approved negative-score/AI corrections remain intact. No formula helper, threshold, rounding, range policy, Redis, model, API settings or original script changed.
