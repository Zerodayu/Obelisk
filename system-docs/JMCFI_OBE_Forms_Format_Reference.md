# JMCFI OBE Forms — Format Reference

Layout reference for the 41 forms (WIN-OBE-F01 – F41) of the **Jose Maria College Foundation, Inc. — Outcomes-Based Education (OBE) Manual**, 1st Edition, document code `JMCFI-M-OBE-07-26` (Appendix: *WIN-OBE Master Forms Package*).

Scope: the **structure** of each form — header band, sections, exact table columns, row labels, rating scales, encoding rules, and signature blocks — so blank forms can be rebuilt (Word, Google Docs, LMS quiz, database form). Narrative guidance from the manual is condensed to the rules that define a field.

Source of truth: `JMCFI_OBE_MANUAL_2026_OCT-29_2026.pdf`, pages 92–391.

---

## 1. Anatomy of every form

Every one of the 41 forms follows the same skeleton. Reproduce these parts in this order.

| # | Block | Content |
|---|---|---|
| 1 | Form code line | `WIN-OBE-Fnn \| Form Title` |
| 2 | Metadata band | 4 columns, one row: `PDCA PHASE` · `EVIDENCE TYPE` · `DEADLINE` · `RETENTION` |
| 3 | Responsible party | `Responsible Party:` followed by the routing/approval chain, e.g. `Faculty → Program Chair → AQAU`; often ends with a frequency note (`One per course per semester`, `Annual`) |
| 4 | Purpose | `PURPOSE:` paragraph stating what the form records and which forms it feeds |
| 5 | Printed rules | Optional: formula, benchmark, data-completeness rule, escalation trigger, retention warning |
| 6 | Sections | Lettered `Section A`, `Section B`, `Section B-1`… or numbered `Part 1`, `Part 2`… with sub-parts `2.1`, `2.2` |
| 7 | Fill-in header fields | Labelled fields with unit/format in brackets, e.g. `Date Submitted: MM/DD/YYYY`, `Academic Year (e.g., 2026–2027)` |
| 8 | Tables | Column headers in Title Case, an empty data matrix, prefilled row labels (codes/PLOs/CLOs), and a closing total row (`SECTION AVERAGE`, `Coverage Check`, `TOTAL`) |
| 9 | Signature block | Role-labelled signature lines + `Date:` lines, e.g. `Prepared by (Program Chair)` / `Validated by (PAC Chair)` / `Received by (AQAU)` |
| 10 | Footer | `JMCFI Institutional Outcomes-Based Education Manual \| M-OBE-07-26` + page number |

### Metadata band values used across the manual

| PDCA phase | Meaning in this manual |
|---|---|
| `PLAN` | Design/alignment output, produced before the AY or term opens |
| `DO` | Implementation record, produced during the term |
| `CHECK` | Assessment/measurement output, produced at midterm, post-term, or per assessment event |
| `ACT` | Improvement output, produced after results are reviewed |
| `PERIODIC` | Annual/periodic indirect evidence (alumni, employers, partners, PEO validation) |
| `ESCALATION` | Produced only when a trigger is met (systemic gap, CAPA, management review) |

`EVIDENCE TYPE` is one of `Direct`, `Indirect`, `Design / Alignment`, `Design / Indirect`, or a mix (`Direct + Perception`). `RETENTION` is `Permanent`, `5 years`, or a stated period; `Permanent` forms are non-disposable and filed with AQAU.

## 2. Encoding conventions

| Convention | Use |
|---|---|
| `☐` / `✓` | Checkbox for checklists and matrix cells; a `Coverage Check` row/column totals the ticks |
| `H` / `M` / `L` | Strength of contribution in mapping matrices (High / Medium / Low); blank = no contribution |
| `I` / `P` / `D` | Introduce – Practice – Demonstrate stage of a CLO/PLO in the curriculum |
| `MET` / `NOT MET` | Status vs. benchmark; direct attainment decides MET status, indirect evidence sets the CQI action |
| 5-pt agreement scale | `5 = Strongly Agree`, `4 = Agree`, `3 = Neutral`, `2 = Disagree`, `1 = Strongly Disagree`; perception score = % rating 4 + 5 |
| 4-level performance | `Exceptional` / `Proficient` / `Basic` / `Below Basic` (portfolio and rubric-scored work) |
| `0–10` rubric | Rubric criterion scores; percentage = `avg ÷ 10 × 100` |
| Attainment level | Per-CLO band derived from attainment %, printed on the assessment forms |
| `N/A` | Written in the first cell when an optional part does not apply |
| Dates | `MM/DD/YYYY` |
| AY / term | `AY 2026–2027`; `1st` / `2nd` / `Summer`; `Prelim` / `Midterm` / `Finals` |

Common thresholds printed on the forms: CLO floor `≥ 70 %`, perception agreement `≥ 80 %` (% rating 4 + 5), survey response rate `≥ 60 %`, data completeness `≥ 60 %` of enrolled students with complete CLO records (else the form is not finalized and a data-recovery plan is filed with AQAU), CQI entry within `4 weeks` of a CLO/PLO gap, and escalation to a Systemic Gap Report after `3+` consecutive failures.

### Section 2 — Computation Guide
`FORMULA 8A — Cohort Average PLO Attainment`
`Cohort PLO Att (%) = Σ Student PLO Att (%) from F24 for students in the year-level cohort ÷ No. of students in cohort`

## WIN-OBE-F36 — PEO Attainment Report (Formulas 12A, 12B, 12C, 13C)

**Purpose:** Determine whether each PEO is MET using the Direct PEO Indicator Rate, with Perceived PEO Attainment reported alongside (Composite optional). Source documents: F32 (Frame B, 5+ years), F35 (PEO section), PAC PEO ratings, PRC licensure results.

**Sections and table layouts**

### Printed rules block
`DECISION RULE (Formula 12C):` A PEO is MET when its Direct PEO Indicator Rate (Formula 12A) is ≥ 70%. The Composite PEO Attainment (Formula 13C) is reported as a supplementary CQI indicator and does NOT determine MET / NOT MET.
`DATA RULE:` Perceived data is used only when the tracer / employer response rate is ≥ 60%. If below 60%, flag for supplemental tracing and report the Direct Rate only in the supplementary composite.
`PERCEIVED TARGET (informational): ≥ 80%.`

### Part 1 — Program and Data Source Information
Fill-in fields: `Program:` · `Academic Year:` · `Alumni Batches Covered (5+ years after graduation):` · `Prepared by:` · `F32 Tracer — Frame B Response Rate (%):` · `F35 Employer — No. of Employers / Response Rate (%):` · `PAC Review — Date / No. of Members Rating:` · `Licensure Data Source (PRC exams, years):` (with ☐ Not applicable — program has no board examination) · `Previous F36 AY (for trend):`

### Part 2 — Computation Guide (Formulas 12A, 12B, 12C, 13C)
Three formula boxes printed verbatim:
- `FORMULA 12A — Direct PEO Indicator Rate`: `Direct PEO Rate (%) = Σ ( Indicator Rate × Weight ) ÷ Σ Weights of the indicators mapped to the PEO`. `Indicators: (1) Employment Rate in PEO-relevant field, (2) Board / Licensure Pass Rate, (3) Professional Advancement Rate — weights as set in Formula 12A.` Programs without a board examination: drop indicator (2) and divide by the remaining weights.
- `FORMULA 12B — Perceived`: `Perceived PEO (%) = Σ ( n₄ + n₅ ) ÷ Σ N × 100 (alumni + employers + PAC, pooled)`. Ratings of 4 or 5 on the 5-point scale for the PEO-mapped items; pool the counts of all three groups; exclude N/A. Apply only when response rate ≥ 60%.
- `FORMULA 13C — Composite`: `Composite PEO (%) = ( Direct PEO Rate × 0.70 ) + ( Perceived PEO × 0.30 )`. Supplementary CQI indicator only. If Perceived data is below threshold, report Direct Rate only and flag for supplemental tracing.
- `FORMULA 12C — Decision:` Direct PEO Rate ≥ 70% → MET; below 70% → NOT MET.
