# OBELISK User Manual

> Jose Maria College Foundation, Inc. — WIN-OBE assessment forms, digitized.
> One manual, one chapter per role. Find your role, do the steps in order.

---

## 1. System Flow

Every form follows the PDCA cycle. The chain of data, first to last:

```
PLAN                Curriculum Map → Calendar → Targets → Budget
                          │
DO                  Class-record upload ◄── the foundation
                    → Mid-Cycle Summary · Peer Obs · Surveys
                          │
CHECK               Course Assessment Report (CAR) ◄── the hub
                    → CLO Summary → PLO Summary → Cohort Tracking
                    Exit/Perception surveys · Capstone & Portfolio panels
                          │
ACT                 Gap Analysis → CQI Action Plan → Closing-the-Loop
                    (3+ consecutive failures → Systemic Gap → CAPA)
                          │
Annual Report → Institutional Review (VPAA + President)
```

**One line:** the Curriculum Map promises → the upload records what students did → the CAR summarizes it → summaries roll up to program level → anything below 70% triggers the CQI loop → the year is signed off at the Institutional Review.

**Five rules that apply to everyone:**

1. **70% floor** — every target, benchmark, and status (MET/NOT MET) is computed server-side against a hard ≥70% minimum. You never type a status yourself.
2. **At-risk is automatic** — any student below 70% on any CLO is flagged by the system from your upload. You document the fix in an Action-Taken Record; the flag clears only when that record is fully approved.
3. **Every approval chain ends at the VPAA** — the system routes each submission up the ladder; no rung can be skipped.
4. **You cannot approve your own submission** — a colleague of your role must sign it.
5. **Loop status is computed** — Closing-the-Loop reads CLOSED only when all five closure conditions are documented; otherwise it stays OPEN.

## 2. Faculty

**Where to start:**

1. Open `/dashboard` and pick your **Academic Context** (program → term → class section). Every form inherits this — pick once.
2. Sidebar → **Upload class records** → drop your AUN-OBE Excel/CSV → review the preview → confirm. At-risk flags appear automatically.
3. Mid-cycle: file the **Mid-Cycle Summary** with the at-risk watchlist.
4. Term end: generate and complete the **CAR** (parts 2–4 come from your upload; you write parts 5–6), then file an **Action-Taken Record** for every at-risk student.
5. Track everything under **My Submissions**.

**What you do:**

| Form | Note |
| :--- | :--- |
| Class-record upload | The foundation — no upload, no downstream data |
| Mid-Cycle Summary | Term snapshot + at-risk watchlist → Program Chair |
| CAR (Course Assessment Report) | The hub — Chair → Dean → AQAU → VPAA |
| Action-Taken Record | Clears at-risk flags only after final approval |
| CLO Attainment Summary | Full-term CLOs per cohort |
| Peer Observation / Perception Survey / Exit Survey | Surveys before grades are released |

You prepare forms only — you never approve other people's.

## 3. Program Chair

**Where to start:**

1. Setup: file the **Curriculum Map** (the CLO–PLO matrix every other form must match), the **Assessment Calendar** (institutional milestones pre-seeded — adjust, don't delete), and the **Target-Setting Matrix** (≥70% per PLO per cohort).
2. During the term: work your **Pending Approvals** inbox — faculty CARs, mid-cycle summaries, surveys, and Action-Taken records reach you first.
3. Term end: compile the **PLO Attainment Summary** and update the **Cohort Tracking Sheet** (Permanent record — the accreditation backbone).
4. Anything below 70%: **Gap Analysis** (6 fixed root causes) → open a **CQI Action Plan** entry with a named owner and measurable KPI.
5. Close the year: file the **Closing-the-Loop Report** (mandatory) and the **Annual Program Report (APAR)** — the APAR is blocked until the Cohort Tracking Sheet is attached and approved.

**What you do:**

| Form | Note |
| :--- | :--- |
| Curriculum Map · Calendar · Target-Setting | Setup — filed once, read by everything |
| Review faculty submissions | First approver on everything |
| PLO Summary · Cohort Tracking | Roll-up to program level |
| Gap Analysis → CQI Action Plan | Live across cycles |
| Exhibition Industry Feedback | Y4 exhibition, ≥3 industry guests |
| Closing-the-Loop Report | Mandatory — non-submission is a violation |
| APAR (Annual Program Report) | Gated on approved Cohort Tracking |

## 4. Dean

**Where to start:**

1. Approve chairs' calendars and targets; submit the **Assessment Budget** directly to the VPAA.
2. Work your **Pending Approvals** inbox — your endorsement is the sign-off before anything leaves the college.
3. Own the PLOs: `/plo-management` — PLO creation, editing, and retirement are **yours alone**, no exceptions for anyone else.
4. Monitor budget expenditure and CQI implementation through **Resource Monitoring**.
5. When a PLO-cohort fails **3 consecutive cycles**: file the **Systemic Gap Report**, then formulate the **CAPA Plan** with the VPAA.

**What you do:**

| Form | Note |
| :--- | :--- |
| Assessment Budget | Fixed line items → straight to VPAA |
| Endorsements | CARs, PLO summaries, CQI plans, APAR |
| PLO Management | Exclusive — dean only |
| Resource Monitoring | Budget spend + CQI implementation tracking |
| Systemic Gap Report | On 3 consecutive failures → VPAA |
| CAPA Plan | Structural fix, senior-leader owned, AQAU-monitored |

---

## 5. AQAU

**Where to start:**

1. Work your **Pending Approvals** inbox — you sit on nearly every chain after the Dean, checking accreditation readiness (CHED/PACUCOA) before data reaches the VPAA.
2. Validate the CQI loop: when a **Closing-the-Loop Report** or **CAPA Plan** arrives, verify the five closure conditions' evidence is real. The status is computed — you check what's behind it.
3. Audit the **Cohort Tracking Sheet** — Permanent-retention evidence, the first thing accreditors pull.
4. Confirm graduation-cluster compilation in `/archives`.
5. Compile the **Institutional Management Review** record for the VPAA's review meeting (program APAR compliance, institutional CQI completion ≥70%, pending CAPAs).

**What you do:**

| Duty | Note |
| :--- | :--- |
| Approve forms on the chain | Verify, never create data |
| Validate Closing-the-Loop / CAPA | Five conditions, hard-computed |
| Cohort Tracking audit | Permanent accreditation evidence |
| Cluster compilation confirm | Releases a graduation cluster |
| Institutional Review record | You prepare, VPAA presides and approves |

You file, monitor, and receive — program data always comes from chairs and faculty.

---

## 6. VPAA

**Where to start:**

1. Work your **Pending Approvals** inbox — every one of the chains ends with you. This is your standing duty.
2. **Archive** approved submissions in `/archives` — only you can lock a record into permanent, immutable storage for accreditation audits.
3. Decide the escalations that reach the top: **Systemic Gap Reports** and **CAPA Plans**, plus final approval on **APARs**.
4. Preside the **Institutional Management Review** with the deans and AQAU; forward decisions to the President.
5. As needed: generate **AI strategic insights** (your exclusive button — runs on PII-scrubbed, institution-wide data; AQAU may view, only you generate).

**What you do:**

| Duty | Note |
| :--- | :--- |
| Final approval on everything | Last signature before institutional fact |
| Archive approved forms | Sovereign archival authority |
| Budget authorization | Deans' Assessment Budgets |
| Systemic Gap / CAPA decisions | The escalation path |
| Preside Institutional Review | With President, deans, AQAU |
| Generate AI insights | VPAA-only |

You never prepare forms — you review, decide, generate insight, and archive.
