Finding: as on the mid-cycle form, the status enums are unvalidated strings.
Sending `implementationStatus:"implemented"` (the requirement-word, not the
enum) reached Prisma and returned HTTP 500 with a raw `createMany` error; the
accepted values are `fully` / `partially` / `not_yet` (`CqiImplementationStatus`),
and `acquired` / `pending` / `not_acquired` / `na` for `AcquisitionStatus`. The
model declares both as `t.Optional(t.String())`, so the API answers 500 rather
than 422 for a bad value.
